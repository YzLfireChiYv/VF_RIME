# VF RIME

可配置的 Rime 关联输入方案与配套小狼毫；一体化安装、更新和离线包正在开发。

目标：在线版和离线版均提供单文件 Windows EXE，负责配套本体、方案及数据安装，
支持检查更新、备份与失败恢复，保留用户词库、学习数据及 custom 配置。

**当前是源码预览阶段，尚无可安装发行版。** 更新清单 available=false，不能据此下载空包。
source-preview/ 包含已核对的三份原生补丁、18 个原创框架审阅模块及独立演示，
不等于完整日用方案。完整依赖、干净环境构建及安装器仍待接通。

- 原创工具：MIT；修改自上游的源码和各数据包保留各自许可。
- 本体基线：Weasel 0.17.4、librime 1.13.1，配套 Lua/native 扩展见源码版本清单。
- 默认稳定通道；nightly 独立，不会自动改写 stable 更新入口。
- 更新入口：updates/stable.json、updates/nightly.json。
- 不包含私人 custom、用户库、输入历史、口癖表或旧私有 Git 历史。

公开仓库使用标准 GitHub 托管构建机器。初始每夜任务检查源码导出清单；
完整安装器构建任务完成后继续接入同一管线，当前不声称已产出安装器。
