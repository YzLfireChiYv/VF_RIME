# Known limits and scope

- This is a source preview, not an installer or the complete daily scheme.
- The 18-module subset has intentionally unbundled dependencies; only the new
  dictionary-free demo is self-contained at the Lua/schema layer.
- Source patch application and four synthetic demo cases were checked; no fresh
  clean-machine binary build, macOS/Linux/Android physical acceptance or new
  quantitative performance comparison is claimed.
- The original private daily line passed 57 engine checks and 5 preset checks.
  Those fixtures depend on private workspace support and are not shipped or
  presented as publicly reproducible tests in this candidate.
- External software, online translation, general networking and image paste are
  not product capabilities yet. An earlier independent worker prototype is not
  included as if it were a connected input-method feature.
- A real rod UI needs the matching modified client/core/Lua combination. Other
  frontends should use flat real candidates, not pretend to have native rods.
- Signed binary releases are outside this source preview. Use the publication
  repository maintained by the project owner for issue and contact information.
