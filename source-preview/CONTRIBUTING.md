# Contributing

Use a small change with a concrete before/after case. Keep input state, association
preset, source identity, visible position and submitted payload distinct. Main
row is display row1; first rod item row2. Internal array/output indexes are not
display coordinates. Associated results do not recursively become new sources.

Use fixed, finite key actions; do not reopen an unrestricted legacy key chain.
Keep expensive work off ordinary per-key candidate paths. Add only representative
checks needed for the changed boundary; do not replace small tests with a huge
matrix or copy live word databases into fixtures.

Retain upstream license/attribution. Add only original or clearly authorized
data with a fixed source and version. Do not submit private words, snippets,
credentials, machine paths, installation identities or real user databases.
Report private-data incidents through a private channel once the repository
provides one, rather than posting user content publicly.
