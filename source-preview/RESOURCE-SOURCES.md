# Optional resources, acquired separately

The standalone example needs no dictionary or gram. Production-scale resources
are not distributed or automatically fetched by this preview. RESOURCE-SOURCES.json
records the specific public Wanxiang data assets used by the earlier daily line;
verify each file hash and its actual upstream data terms before using it.

https://github.com/amzxyz/rime-wanxiang-data
https://github.com/amzxyz/rime-wanxiang

Current unknown-provenance English and emoji mapping tables are not download
recommendations and are excluded, including the embedded Lua copy of emoji data.
Professional dictionary/emoji sources are a separate investigation; no new
dictionary has been adopted by this source preparation.
